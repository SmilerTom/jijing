# 基金交易计算器界面美化设计

## 目标

在不改变计算公式、流水状态、分页和弹窗行为的前提下，提升 `/t-calculator` 的深色交易终端体验，让账户快照更容易扫描、流水表更易读、输入状态更明确，并保持移动端可操作。

## 视觉方向

采用“专业交易终端”风格：深色海军蓝作为底色，沿用项目现有青色主色、蓝色模块色、绿色入仓/正收益和红色出仓/负收益语义。使用弱光晕、细边框和克制阴影建立层次，不引入霓虹玻璃或大面积渐变装饰。

## 页面结构

1. 顶部标题区：状态信息作为小标签，基金名称作为主标题，恢复默认按钮弱化显示。
2. 账户快照：保持 3×2 指标卡布局，持仓市值和盈利率作为主要指标，回本净值使用青色强调，编辑状态保持现有输入结构。
3. 入仓/出仓流水：标题、说明和加号按钮在同一视觉基线；表头、数字、输入框和状态行使用统一间距与字号。
4. 表格交互：保留横向滚动、分页和待次日计算行；待处理行使用独立状态色和标签，不能与已计算数据混淆。
5. 弹窗与分页：沿用现有结构，统一按钮、边框、焦点和间距，移动端允许分页控件换行。

## 色彩与排版

- 复用现有 CSS 变量，不修改全局主题。
- 青色用于主操作和回本净值，蓝色用于模块标题，绿色用于入仓与正收益，红色用于出仓与负收益。
- 金额、份额、净值使用等宽数字字体；标题、标签、说明保持清晰的字号层级。
- 输入框默认融入卡片背景，编辑/聚焦时显示青色边框和可见焦点环。
- 行 hover、分页禁用态和待处理状态只使用轻量反馈，避免动画干扰账目阅读。

## 响应式与可访问性

- 桌面端维持紧凑的 3×2 快照网格和整宽流水区。
- 390px 左右移动端维持双列指标卡，流水表在容器内横向滚动，按钮和输入不小于可操作尺寸。
- 保留语义标题、表格表头、可见标签、键盘焦点和现有 ARIA 名称。
- 颜色不作为唯一状态信号；待处理状态同时显示“待次日计算”文字。

## 实施边界

- 主要修改 `app/t-calculator/calculator.module.css`，必要时只给现有 JSX 元素补充样式 class。
- 不新增依赖、不改 `calculator.mjs`、不改 localStorage 数据协议、不调整任何计算逻辑。
- 不修改首页、全局主题或其他基金页面。

## 验收标准

- 桌面端账户快照、流水标题和表格层级明显，表格列保持对齐。
- 输入框、加号、编辑、分页按钮拥有明确 hover/focus 状态。
- 入仓金额、出仓金额、收益率继续保持既有颜色语义。
- 待次日记录、分页和弹窗行为与美化前一致。
- 390px 移动端无页面级横向溢出，表格仅在表格容器内滚动。
- 页面无新增控制台错误；聚焦 ESLint、公式自检和 `git diff --check` 通过。
